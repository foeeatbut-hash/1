# Портативная версия Flux

Готовый `.exe` больше не лежит в репозитории. Он публикуется в **GitHub
Releases** — целым файлом, без разбивки на части и без склейки вручную.

## Как скачать и запустить (Windows)

1. Откройте страницу выпусков репозитория (вкладка **Releases**).
2. В последнем выпуске скачайте `Flux-<версия>-x64.exe`.
3. Запустите скачанный файл.

Установка не требуется — это портативная сборка для Windows x64. Данные
программа хранит рядом с собой, поэтому её можно носить на флешке.

## Как выпускается сборка

Собирает GitHub Actions (`.github/workflows/build-portable.yml`), не машина
разработчика. Достаточно поднять версию в `package.json` и закоммитить с
меткой `[build-exe]` в сообщении — прогон соберёт exe и приложит его к
выпуску с тегом `v<версия>`. Тот же файл дополнительно остаётся артефактом
прогона в течение 30 дней.

Раньше exe разбивался на части по 95 МБ и коммитился в ветку: каждая сборка
навсегда добавляла к репозиторию около 125 МБ, а пользователю приходилось
склеивать части `.bat`-файлом. Обе неприятности убраны.

# Макеты

Исходники холстов с разбором оформления. В приложение не входят и ниоткуда не
импортируются — это материал для решения, а не код программы.

`flux-review/` — разбор оформления версии 0.64.0: что ломается на экране, что
происходит при сжатии окна, куда переводить цвета мимо палитры.

Собранный холст сюда не кладётся: это двухмегабайтная сборка редактора, которая
пересобирается из этих исходников одной командой. В репозитории держим только то,
что написано руками.

# Репродукции для полки

Сюда кладутся снимки картин, которые показывает полка в шапке помощника
(см. src/art/photos.tsx). Папка читается сборщиком целиком — вписывать файл
куда-то ещё не нужно, достаточно положить его сюда.

**Имя файла** — идентификатор работы из `src/art/works.ts`: `mona.jpg`,
`kiss.webp`, `bogatyrs.png`. Расширение любое из jpg, jpeg, png, webp, avif.

**Размер** — 500–900 точек по большей стороне, файл до 150 КБ. Больше не
нужно: в раме картина занимает от 50 до 150 точек. Соотношение сторон
снимается с самого файла, кадрировать ничего не надо.

**Чего здесь быть не должно** — перерисовок, стилизаций и изображений,
созданных нейросетью. Смысл полки в том, чтобы человек узнал знакомую
работу, а похожая подделка узнаётся ровно наоборот.

**Права.** Все авторы из списка умерли более семидесяти лет назад, работы
находятся в общественном достоянии. Точный снимок плоской работы из
общественного достояния собственных прав не создаёт, поэтому такие файлы
используются свободно.

**Пока файла нет** — работа на полке не показывается вовсе. Для восьми из
них есть нарисованный запас (src/art/canvases.tsx), он и покажется.

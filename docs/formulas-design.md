# Формулы документа: плашки с названием

## Что не так сейчас

В шаблоне титульного листа поле вставляется плашкой с человеческим названием
(«Название документа»), а формула — плашкой с выражением: `ƒ date & " г."`.
Инженер видит в документе кусок кода. Собрать составное значение может только
тот, кто помнит синтаксис, а изменить порядок «день-месяц-год» нельзя вовсе —
дата приходит уже собранной строкой.

## Что должно быть

Формула — **именованная вещь**, а не строка выражения. В документе видно
название: «Дата», «Инициалы сотрудника», «Подпись», «Шифр с ревизией».
Настройка формулы живёт в её карточке, а не в тексте документа.

```
┌─ титульный лист ──────────────────────────────────────┐
│  Разработал   [Инициалы сотрудника]  [Подпись]        │
│  Дата         [Дата]                                  │
│  Документ     [Шифр с ревизией]                       │
└───────────────────────────────────────────────────────┘
```

## Устройство

### Формула = название + вид + настройка

Четыре вида, от простого к сложному. Три первых собираются мышью, четвёртый —
для тех, кому нужно считать.

| Вид | Что делает | Пример |
|---|---|---|
| **Значение** | одно поле программы, с настройкой вывода | «Дата» — поле `date`, порядок Д.М.Г |
| **Текст** | постоянная надпись | «г.», «Лист» |
| **Сборка** | несколько частей подряд с разделителями | «Шифр с ревизией» = шифр + « рев. » + ревизия |
| **Выражение** | как сейчас: `+ - * / &`, скобки, поля | `pages - page & " осталось"` |

**Сборка** — главное, ради чего всё затевается. Строка частей, каждую можно
переставить, убрать, заменить. Разделитель у части свой, поэтому «пусто →
разделитель не печатается» решается само: часть без значения выпадает вместе
со своим разделителем, и в документе не остаётся висящего дефиса.

### Настройка «Значения»

У поля-даты — порядок и вид, ровно то, что просили:

```
Порядок   ( Д.М.Г )  ( М.Д.Г )  ( Г-М-Д )
Месяц     ( 05 )  ( мая )  ( Май )
Год       ( 2026 )  ( 26 )
Разделитель  [ . ]
                            → 16.08.2026
```

У поля-человека — как показать: `Иванов Иван Иванович` · `Иванов И. И.` ·
`И. И. Иванов` · `Иванов`. Это и есть «Инициалы сотрудника» — не отдельное
поле в базе, а вид вывода того же ФИО.

Предпросмотр значения показывается прямо в карточке и пересчитывается на
каждое изменение. Гадать не приходится.

### Подпись сотрудника

Новое поле профиля: картинка подписи. Задаётся при заведении сотрудника и
меняется позже — в карточке сотрудника и в своём профиле.

- принимается PNG/JPG, хранится в профиле;
- кнопка **«Убрать фон»**: близкие к белому точки делаются прозрачными,
  порогом можно двигать. Скан с листа сразу годится, обрезать в редакторе
  не нужно;
- в карточке подписи задаётся **высота в миллиметрах** — подпись в документе
  не должна прыгать от того, каким разрешением её отсканировали;
- в документе плашка «Подпись» подставляет картинку по высоте строки.

Чья подпись — часть настройки формулы: **автора документа**, **текущего
пользователя** или **выбранного сотрудника** (для строк «Проверил»,
«Утвердил»).

### Где живёт справочник

Одно место: **Настройки → Документооборот → Формулы**. Оттуда же открывается
кнопкой «＋ Новая формула» из панели вставки в редакторе титула — чтобы не
уходить из документа ради одной формулы.

Формулы **проекта**: их видят все, кто работает над проектом, иначе титул у
коллеги соберётся иначе. Встроенные (Дата, Автор, Подпись, Шифр, Ревизия,
Проект, Заказчик, Страница) идут с программой, их нельзя удалить, но можно
скопировать и переделать под себя.

## Что меняется в коде

| Где | Что |
|---|---|
| `prisma/schema.prisma` | модель `DocFormula`; поле `signatureImage` у `User` |
| `src/screens/titleTemplate.ts` | плашка по идентификатору формулы; сборка и форматы; старые плашки с выражением продолжают работать |
| `src/screens/TitleTemplateEditor.tsx` | список формул вместо поля ввода выражения |
| `server/routes/constructor.ts` | чтение и запись формул, отдача подписи в контекст |
| `src/screens/UsersManagement.tsx` | загрузка подписи в карточке сотрудника |
| `server/routes/users.ts` | сохранение подписи |

Старые шаблоны не ломаются: плашка `data-formula="выражение"` остаётся
работающей, новая — `data-formula-id`. Разбор в `renderTitleHtml` различает их
по атрибуту.

## Чего сознательно не делаем

- **Не даём формулам считать по всему проекту.** Своды по тегам и оборудованию
  уже есть в Конструкторе (`pSum`, `countTag` и прочие). Формула титула — про
  оформление документа, и смешивать эти два языка значит получить третий,
  который никто не знает.
- **Не автоматизируем распознавание подписи.** «Убрать фон» — порог по яркости
  с ползунком и предпросмотром, а не угадывание. Инженер видит результат до
  того, как нажмёт «Сохранить».
- **Не заводим личные формулы.** Документ общий; личная формула у автора
  означает, что у коллеги титул соберётся иначе, и это заметят на печати.
